# Python Beginner Projects

Welcome to my Python Projects repository!

This repository contains small Python projects I developed while learning Python programming. These projects help me practise programming fundamentals and improve my problem-solving skills.

## Projects

### 1. Simple Calculator

A basic calculator that performs arithmetic operations.

**Features:**

* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)
* Handles division by zero

**Concepts Learned:**

* Variables
* User input
* Operators
* Conditional statements (`if-elif-else`)

### 2. Number Guessing Game

A simple interactive game in which the computer selects a random number between 1 and 10, and the user tries to guess it.

**Features:**

* Generates a random number
* Provides hints when a guess is too high or too low
* Continues until the correct number is guessed

**Concepts Learned:**

* `random` module
* `while` loop
* Conditional statements
* User input

### 3. Temperature Converter

A simple program that converts temperatures between Celsius and Fahrenheit.

**Features:**

* Converts Celsius to Fahrenheit
* Converts Fahrenheit to Celsius
* Accepts decimal temperature values

**Concepts Learned:**

* Variables
* User input
* `float()` function
* Conditional statements
* Arithmetic operators

### 4. Age Calculator

A simple program that calculates approximate age using the user's birth year.

**Features:**

* Accepts the birth year
* Gets the current year automatically
* Calculates approximate age

**Concepts Learned:**

* Variables
* User input
* `int()` function
* `datetime` module
* Arithmetic operations

### 5. Student Marks Calculator

A basic program that calculates a student's total marks and average across three subjects: Python, SQL, and Excel.

**Features:**

* Accepts student name
* Takes marks for three subjects
* Calculates total marks
* Calculates average marks
* Displays a student result summary

**Concepts Learned:**

* Variables
* User input
* Integer conversion
* Arithmetic operators
* Output formatting

## Technologies Used

## How to Run the Projects

**Prerequisite:** Install Python 3 on your computer.

Open the terminal in the main `Python_projects` folder and run the commands below.

### Project 1: Simple Calculator

```bash
py Calculator/calculator.py
```

### Project 2: Number Guessing Game

```bash
py Guessing_Game/guessing_game.py
```

### Project 3: Temperature Converter

```bash
py Temperature_Converter/temperature_converter.py
```

### Project 4: Age Calculator

```bash
py Age_Calulator/age_calculator.py
```

### Project 5: Student Marks Calculator

```bash
py Student_Marks_Calculator/student_marks.py
```

**Note:** Make sure your folder names and Python filenames match these commands.
